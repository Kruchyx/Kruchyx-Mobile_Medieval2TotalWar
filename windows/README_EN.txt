KRUCHYX MEDIEVAL MOD STUDIOS — v0.9.2 BROTHER EDITION
=====================================================

HOW TO START
Extract the whole ZIP archive and run START_WINDOWS.bat.
Requires Python 3.10+ with Tkinter. No prebuilt Windows .exe yet.

NEW IN v0.9.2
• Explicit Vanilla Grand Campaign, Kingdoms and mod selection.
• Game installation discovery and manual folder selection.
• Opt-in beta for extracting selected base game definitions into a separate
  cache with the game's own official unpacker.exe — NOT the game folder.
• Source precedence: loose mod definitions over base game and cache files.
• Bilingual sourced gameplay and exploit tutorials with confidence labels.
• Merchant army stacking, resource forts and long-duration diplomacy.
• Diplomacy experiment calculator: illustrative arithmetic, not AI forecast.
• Better English text coverage and academy navigation.
• Retained trainer, older editors and read-only Save Explorer.

LIMITATIONS
• No genuine memory-based Live Trainer or infinite movement toggle yet.
• No editing binary .sav files.
• Packed game extraction depends on the official unpacker version and
  has not been tested on the user's Windows installation.
• English translations of the modern interface have been improved;
  some legacy editor dialogs remain in Polish.
• Rankings compare heuristics, not outcomes of battles or actual per-turn income.

Source links are available inside Secrets & exploits and the two guides.
Made by Kruchyx.

OPTIONAL WINDOWS .EXE
Run BUILD_EXE_WINDOWS.bat on a Windows PC with Python and internet to
try packaging a portable folder using PyInstaller. It will ask before
installing PyInstaller. Send the entire generated dist folder to the
recipient. This workflow has NOT been tested on Windows here.
