# Kruchyx Mobile v0.9.6
Projekt Flutter dla Androida i iPhone'a. Flutter: 3.47.8.
- Android: `flutter create --platforms=android --org com.kruchyx .`, `flutter pub get`, `flutter test`, `flutter build apk --release`.
- iOS (Mac + Xcode): `flutter create --platforms=ios --org com.kruchyx .`, `flutter pub get`, `flutter test`, `flutter build ios --release --no-codesign`.
- Na Githubie instalator APK powstaje w workflow **Kruchyx v0.9.6 - Android APK**, EXE w Windows, iOS unsigned build na macOS (manual).
- Pakiet iOS unsigned nie jest instalatorem `.ipa` do bezpośredniej instalacji. Wymaga podpisania i konfiguracji Apple.
- Źródła jednostek są demonstracyjne do chwili importu raportu Windows. Autorskie emblematy nie są oryginalnymi herbami z gry.
