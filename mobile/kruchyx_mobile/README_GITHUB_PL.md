# Kruchyx Mobile v0.9.6 — instrukcja dla GitHuba

**TEN FOLDER JEST CZĘŚCIĄ MONOREPOZYTORIUM.** Nie wgrywaj go pod dodatkowym katalogiem na głównym poziomie. W repo root muszą być foldery `.github`, `mobile`, `windows` i `README.md`.

GitHub Actions znajduje się w głównym `.github/workflows/build-android.yml`, a Flutter w `mobile/kruchyx_mobile/`. Najprościej wgrać całą paczkę v0.9.6, zgodnie z `docs/INSTRUKCJA_GITHUB_PL.md` z katalogu głównego.

Po zielonym przebiegu: Actions → Artifacts → `Kruchyx-Android-v0.9.6-APK` → pobierz ZIP → rozpakuj APK. Na iPhone'a nie można instalować Android APK; projekt iOS wymaga Maca i podpisu Apple.

Atlas korzysta z autorskich emblematów, 22 profili frakcji i 24 miast. Domyślne ceny jednostek są wyłącznie DEMO; zaimportuj raport Windows, aby zobaczyć właściwe statystyki.
